# 题型扩展实施状态：HTML SDK 2.3

2026-10-07 当前提供单选、多选、判断、完形、阅读、排序、翻译、作文八种外部包。最新接口为 SDK 2.3，包格式 2；应用不预装或自动授权。缺少对应包时暂停执行并保留题库和资源。

## 已实现

- 八种独立扩展源码与真实样例题库位于 extensions/packages；判断题为 2.3.1 的 11 文件手写模板，其余为 2.3.0 的构建式模板。
- 编辑 HTML、练习 HTML、独立默认 Question JSON 和同步题型逻辑。
- SDK 2.3 的 page.register/save/requestAction，统一上下文、写入队列、离开屏障、上下文版本和内存回执校验。旧业务命名空间、旧方法分发及页面兼容分支已删除；只加载 pageApi: simple，旧扩展提示升级。私有宿主服务继续供结构化接口调用，扩展无法直接请求。
- SDK 2 清单、离线打包、版本化安装、手动导入与权限确认；没有启动自动安装、自动授权或自动源码监听。
- 编辑器统一使用 `ExtensionEditorFields`，练习使用通用 HTML 适配层。
- 提交前隐藏答案与解析；宿主统一保存作答、确认提交、评分记录、重试、白板快照、历史与统计。
- 单选、多选题干和选项为普通文本，解析支持公共富文本。
- 网页只读预览复用 practice.html，提供样例预览与下载；独立开发目录提供文件变更预览。
- Schema 在可终止 Worker 中校验，并限制节点、深度、正则和计算预算；Java 宿主再次校验。
- Windows 页面通过隔离 iframe 直接渲染；规则执行、消息传输、浏览器临时目录等边界见对应后端与安全文档。
- 移除旧七题型扩展、配置式实现、原内置注册器和题型专用网页渲染/规则/编辑代码。
- 原题库模型与 codec 保留，防止删除保留题库中的文章、答案和资源；缺少扩展时不执行旧题卡。

## 运行入口

1. `ExtensionPackageStore` 验证并读取 SDK 2 包。
2. `ExtensionManager` 只扫描用户已安装的包，启动规则引擎并登记版本。
3. `QuestionTypes` 只登记已安装扩展，缺失类型使用只读数据兼容占位。
4. 编辑宿主加载 editor.html；`SharedPracticeViewModel` 投影练习数据，网页宿主加载 practice.html。
5. `PracticeSessionService` 保存通用答案并调用扩展评分；评分提交后历史固定该版本和数据。
6. html-ui.js 构造上下文并适配权限；simple-api.js 执行保存/操作白名单，frame-client.js 向隔离页面只暴露对应 API，simple-client.js 管理加载、写入和离开屏障。

具体参数见 [SDK 2.3 接口参考](../extensions/SIMPLE_PAGE_API.md)，开发和打包见 [指南](../extensions/DEVELOPMENT_GUIDE.md)。运行边界见 [WebView2](../extensions/WEBVIEW2_BACKEND.md)、[规则隔离](../extensions/RUNTIME_ISOLATION.md)、[数据校验](../extensions/DATA_VALIDATION.md)。
