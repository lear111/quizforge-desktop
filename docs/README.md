当前示例扩展是单选、多选、判断题，应用不自动安装或授权。当前实现以代码地图和 SDK 为准；产品设计与草案中的其他题型、AI 能力须按各文档的状态判断。

## 阅读路线

1. 新人指南：运行并导入扩展。
2. 代码地图第 1～2 节：认识模块和桌面职责。
3. 代码地图第 3 节：选择一条业务链路，沿入口追踪状态变化。
4. 新增题型：五步模板 → 完整开发指南 → SDK 和公共 UI 参考。
5. 文件或资源问题查题库格式，启动与热更新问题查开发说明。

## 维护原则

- 当前手册描述现有能力，设计文档标明目标与待实现部分。
- 调用入口和职责放代码地图，运行操作放新人指南，详细题型教程放扩展开发指南，文件协议放题库格式文档。
- 修改包位置时更新引用、同名测试包和现行文档；正式业务代码不放入演示包。
- 网页行为修改源码后重新构建，不直接维护生成资源。
- 根据改动选择编译、定向测试或真实浏览器验收；历史阶段的测试数量不作为当前通过证明。

白板与学习面的早期契约、验收记录位于 `quizforge-desktop-app/editor-web/draft-canvas/`。其中的阶段题型、旧路径和旧 DTO 应按文首迁移说明理解；当前代码位置查代码地图。
