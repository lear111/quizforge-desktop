页面的三个主要通信入口：`QF.page.register`、`QF.save`、`QF.requestAction`。辅助命名空间为 `dom / ids / content / ui / layout`。历史/预览复用练习页，白板默认由应用提供，最终统计由应用管理。

旧页面 API 的代码和兼容入口已经移除；扩展必须声明 `pageApi: "simple"` 并使用上述入口。旧安装包和数据仍保留，但旧页面不能继续渲染，需升级扩展；历史记录的冻结版本不会自动改写。

应用不预装题型。当前提供单选、多选、判断、完形、阅读、排序、翻译、作文八个外部包；八个包均为 2.3.2。包版本与 SDK/dataVersion 独立。

## 维护约定

接口变动同步实现、权限与数据校验、定向测试及 SIMPLE_PAGE_API；版本和构建差异同步 packages/README。删除废弃接口说明时同步清理文档引用。历史数据依赖的版本化安装包与运行实现按实际使用情况管理，不随文档清理删除。
