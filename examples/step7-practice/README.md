# Step 7 练习题库样例

这组文件用于手动验收 QuestionBank 的 Practice / Edit 模式：4 道题，包含 2 道单选和 2 道多选。

1. 将 `Java集合示例.qdoc` 和 `Java集合练习.qbank` 复制到同一个现有 Workspace 的任意目录。无需放入默认分类目录。
2. 在 QuizForge Desktop 中刷新文件树，打开 `Java集合练习.qbank`。默认进入 Practice；右上角的单个模式按钮可切换到 Edit。
3. 两个文件的来源关系通过 QDoc assetId、contentId 和 sectionId 建立。若修改了 QDoc 内容，题库的来源状态会变为不同修订；题库文件本身仍可打开。

这两个文件是可复制的示例资产，不是程序运行时 Workspace 数据。
