# Java 集合示例

## 常用集合
<!-- qf:id=chapter_collections_demo -->

<!-- qf:anchor=section_arraylist_demo -->
### ArrayList
<!-- qf:id=section_arraylist_demo -->

ArrayList 基于可扩容数组，保持元素的插入顺序，允许重复元素，按索引访问的时间复杂度为 O(1)。

<!-- qf:anchor=section_hashset_demo -->
### HashSet
<!-- qf:id=section_hashset_demo -->

HashSet 基于哈希表，不保存重复元素，不保证遍历顺序；在正常散列条件下，contains 的平均时间复杂度为 O(1)。
